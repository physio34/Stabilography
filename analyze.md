Анализатор стабилограмм (Stabilogram Analyzer)

Утилита для обработки биомеханических данных, полученных со стабилометрических платформ. Программа выполняет расчет пространственных, временных и частотных характеристик движения центра давления (ЦД), а также автоматически формирует интерактивные отчеты в форматах HTML и XLSX.
Основные возможности
    Пространственно-временной анализ:
        Длина пути и средняя скорость движения ЦД.
        Среднеквадратическое отклонение (RMS) по осям X и Y.
        Размах (амплитуда) по осям X и Y.
        Площадь статокинезиограммы (расчет по 95% доверительному эллипсу на основе SVD-разложения ковариационной матрицы).
    Частотный анализ (FFT):
        Спектральная плотность мощности (PSD) с использованием окна Хэннинга.
        Общая мощность спектра.
        Средняя (центроидная), медианная и пиковая частоты для каждой оси.
    Генерация отчетов:
        HTML: Интерактивные графики (статокинезиограмма с эллипсом, временные ряды, спектры мощности) + сводная таблица метрик.
        XLSX: Структурированный файл с листом метрик и листом сырых данных.

Требования к окружению
    Python 3.9+
    Библиотеки: pandas, numpy, plotly, openpyxl

Установка
    Клонируйте репозиторий или скопируйте файл main.py в вашу рабочую директорию.
    Установите необходимые Python-библиотеки: pip install pandas numpy plotly openpyxl

Формат входных данных:
    Программа принимает на вход файлы форматов .csv или .xlsx.

Требования к структуре данных:
    Файл должен содержать обязательные колонки с названиями X и Y (координаты центра давления в миллиметрах).
    Опционально может присутствовать колонка Time (время в секундах). Если её нет, программа автоматически сгенерирует временную шкалу с частотой дискретизации 50 Гц (стандарт для большинства стабилоплатформ).

Использование
    Запуск осуществляется из командной строки:
    python main.py <путь_к_входному_файлу> [-o <директория_для_отчетов>]

Аргументы:
     input_file (обязательный): Путь к входному файлу с данными (CSV/XLSX).
     -o, --output_dir (опциональный): Директория для сохранения отчетов. По умолчанию используется текущая директория (.).

Пример запуска
     python main.py data/patient1.csv -o ./reports

Выходные данные
    В указанной директории (или в текущей) будут созданы два файла, названных по принципу <имя_исходного_файла>_report.<расширение>:
    <имя>_report.html — Интерактивный веб-отчет, включающий:
         График статокинезиограммы (траектория ЦД в плоскости X-Y) с наложенным 95% эллипсом.
         Графики изменения координат X и Y во времени.
         Графики спектральной плотности мощности (PSD) для осей X и Y (в логарифмическом масштабе).
         HTML-таблицу со всеми рассчитанными метриками.
    <имя>_report.xlsx — Excel-книга с двумя листами:
         Лист "Метрики": Содержит названия показателей и их значения.
         Лист "Сырые данные": Исходные данные, используемые для анализа.

Список рассчитываемых метрик:
Общее время (с)	Длительность записи
Частота дискретизации (Гц)	Определяется из временной шкалы (или 50 Гц по умолчанию)
Длина пути (мм)	Сумма евклидовых расстояний между соседними точками
Средняя скорость (мм/с)	Длина пути, деленная на общее время
СКО по оси X/Y (мм)	Среднеквадратическое отклонение (разброс относительно среднего)
Размах по оси X/Y (мм)	Разница между максимальным и минимальным значением
Площадь 95% эллипса (мм²)	Площадь эллипса, охватывающего 95% точек траектории ЦД
Общая мощность X/Y (мм²/Гц)	Интеграл спектральной плотности мощности
Средняя частота X/Y (Гц)	Центроид спектра (средневзвешенная частота по мощности)
Медианная частота X/Y (Гц)	Частота, делящая спектр мощности на две равные по площади части
Пиковая частота X/Y (Гц)	Частота с максимальной мощностью (доминирующая частота)

Математические заметки
     Расчет площади эллипса: Используется ковариационная матрица векторов X и Y. Через собственные векторы и значения (SVD) определяются главные оси эллипса. Для получения 95% доверительного интервала полуоси умножаются на квантиль распределения хи-квадрат с 2 степенями свободы (2.4477).
     Частотный анализ: Применяется быстрое преобразование Фурье (FFT). Для предотвращения эффекта утечки спектра (spectral leakage) сигнал предварительно умножается на окно Хэннинга. Постоянная составляющая (DC offset, 0 Гц) удаляется перед анализом.
